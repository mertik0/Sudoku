## What is Sudoku?:

Sudoku is a logic based game. In classic sudoku, the objective is to fill a 9×9 grid with digits so that each column, each row, and each of the nine 3×3 subgrids that compose the boxes contains all of the digits from 1 to 9. [Read more](https://en.wikipedia.org/wiki/Sudoku).
